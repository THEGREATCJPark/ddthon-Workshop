# 페르소나 (Personas)

> 범위: 승인된 요구사항의 주요 사용자 유형 2개 (Q4=A).

---

## Persona 1: 다인 (고객 / 테이블 태블릿 사용자)

| 항목 | 내용 |
|---|---|
| **역할** | 매장 테이블에 앉아 태블릿으로 직접 주문하는 손님 |
| **기술 수준** | 일반 스마트폰/태블릿 사용자 수준, 별도 학습 없이 즉시 사용 |
| **사용 환경** | 매장 테이블에 고정된 태블릿(브라우저 웹UI), 관리자가 사전 설정·자동 로그인 상태 |
| **목표** | 대기 없이 빠르게 메뉴를 보고, 원하는 것을 담아, 간단히 주문하고, 내 주문 상태를 확인 |
| **주요 니즈** | 직관적 카드형 메뉴, 터치 친화 버튼(≥44px), 실시간 총액, 새로고침해도 유지되는 장바구니, 명확한 주문 성공 피드백 |
| **불만/제약** | 로그인·회원가입 절차 원치 않음, 복잡한 UI·느린 반응 싫어함 |
| **관련 FR** | FR-C1, FR-C2, FR-C3, FR-C4, FR-C5 |

## Persona 2: 사장님 (매장 관리자 / 운영자)

| 항목 | 내용 |
|---|---|
| **역할** | 매장을 운영하며 들어오는 주문을 실시간 관리하고 테이블/메뉴를 설정 |
| **기술 수준** | 기본 웹 관리도구 사용 가능, 바쁜 영업 중 빠른 조작 필요 |
| **사용 환경** | 카운터/주방의 PC 또는 태블릿 브라우저, 16시간 세션 로그인 |
| **목표** | 신규 주문을 놓치지 않고 즉시 확인, 상태를 갱신(대기중→준비중→완료), 테이블 세션·메뉴를 관리 |
| **주요 니즈** | SSE 기반 실시간 대시보드(2초 이내), 테이블별 그리드/필터, 신규 주문 강조, 주문 삭제·세션 종료·과거 이력, 메뉴 CRUD |
| **불만/제약** | 주문 누락·지연 표시 곤란, 복잡한 인증 번거로움(단 보안은 필요: JWT·bcrypt) |
| **관련 FR** | FR-A1, FR-A2, FR-A3, FR-A4, FR-A5 |
